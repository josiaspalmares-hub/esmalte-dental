# Clínica Dental El Rosal (proyecto de muestra)

Web y panel de recepción de una clínica dental ficticia en Caracas, hecha para el portafolio de Josías Palmares.

- **Web** (`index.html`): guía "¿Qué te trae por aquí?" que lleva del problema al tratamiento con precio en $ y Bs (tasa BCV de ve.dolarapi.com), lista de precios, primera visita minuto a minuto, equipo, pedido de cita por WhatsApp, mapa y preguntas frecuentes.
- **Panel** (`panel.html`): siguiente paciente, agenda del día, pedidos que llegan desde la web, lo que falta por cobrar y qué días tienen huecos. Datos de muestra; los pedidos hechos en la web se ven aquí porque quedan guardados solo en el navegador.

Hecho con React, TypeScript, Tailwind CSS 4 y componentes de [Magic UI](https://magicui.design) (BlurFade, AnimatedList, NumberTicker). Fotos de Pexels; mapa de OpenStreetMap.

```bash
npm install
npm run dev
npm run build
```
